# Tessox — website

Agency site for **Tessox** (formally Tessox Labs): AI automations with security built in.
Founded by Zaryab Khan.

Plain HTML/CSS/JS with no build step. Open `index.html` to view it locally.

- `index.html`, `style.css`, `script.js`: the live site (automation-first)
- `favicon.svg`: brand icon (PNG exports: `favicon-32.png`, `apple-touch-icon.png`)
- `versions/security-first/`: an earlier security-led version, kept for reference
